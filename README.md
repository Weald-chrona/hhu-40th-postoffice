## 四、内容状态

✅ **已按学院公开信息填写**：数据概览、四秩历程（1960–2026 七个节点）、办学成果、学院简介、发展大事记、专业与学科。

仍需你确认或补充：

| 位置 | 文件 | 说明 |
| --- | --- | --- |
| 建院四十周年 | 全站 | 按“1986 年建系 → 2026 年四十周年”推算，**请与学院口径核对** |
| 联系方式 | `about.html` | 地址暂写“江苏常州 · 河海大学常州校区”，邮箱、电话仍是占位 |
| 全部图片 | `images/` | 仍是抽象占位图，换成学院真实照片（院庆、实验室、校园） |

### 换图片的正确姿势

1. 把新照片放进 `images/`，建议重命名为 `hero.jpg`、`slide-1.jpg` …（**英文小写+连字符**，别用中文名，避免部分环境乱码）
2. 尺寸建议：`hero.jpg` 1920×1080，轮播图 1200×750，统一 **16:10**
3. 图片压缩到 500KB 以内，用 [squoosh.app](https://squoosh.app) 或 TinyPNG，别让网页加载太慢
4. 换完在浏览器里刷新，确认没有变形、没有被裁掉关键部分

### 改配色

打开 `css/style.css` 最上面的 `:root`，改这两个值就能全站换色：

```css
--blue-600: #0e4c92;   /* 主色 */
--gold: #d9a441;       /* 点缀色 */
```
